# travel-planner 旅游规划技能

> 位于 `.agents/skills/travel-planner/`，遵循 OpenAI Agent 规范的项目级技能。
> 任何兼容 Agent（Codex / Cursor / Claude Code / 自建 Agent）将技能根目录指向
> 本项目 `.agents/skills/` 即可加载本技能。

## 功能概述

为用户规划一次城市旅游，输出"未来近一周"的完整情报与路线方案：

| 模块 | 内容 | 数据源 |
|---|---|---|
| 自然因素 | 未来 7 天逐日天气、气温、降水、风力、空气质量、日出日落、穿衣/雨具建议 | 高德天气 API（4 天）+ 天气网站搜索补充（7 天） |
| 人文因素 | 本周活动、展览、演出、节庆、热门景点开放状态、特色美食 | 通用搜索 + 官方渠道精读 |
| 路线规划 | 3~5 个核心景点的每日行程：顺序、交通方式、单段耗时、当日总耗时 | 高德路径规划 API（步行/驾车/公交） |
| 输出 | 结构化旅行报告（逐日情报表 + 人文清单 + 按天行程 + 注意事项 + 数据来源） | — |

## 核心原则

- **先问城市，不自作主张**：用户未明确说出目的地城市前，禁止开始任何查询与规划，
  必须停下来询问（城市为必问项；出发地、日期天数、偏好可选，一次问清）。
- **事实纪律**：所有数字来自脚本真实返回 / 搜索真实结果 / 用户输入；查不到就写
  "未获取到"，不编造。未来天气标注"预报仅供参考"。
- **必要时刻用高德**：高德负责地理编码、天气、路径规划；无 Key 时自动降级为搜索，
  并在报告中注明"路线耗时为估算"。

## 使用方法

### 作为 Agent 技能加载

技能根目录指向 `my-agent/.agents/skills/`，触发词如"规划旅游 / 旅游攻略 /
去 XX 城市玩 / 未来一周天气 / 行程安排"即可命中。

### 脚本 CLI（可直接手动调用）

```powershell
# 环境变量配置高德 Key（可选，未配置则明确报错并降级）
$env:AMAP_KEY = "你的高德Key"

python .agents/skills/travel-planner/scripts/amap_api.py geocode "北京"
# → {"city":"北京","adcode":"110000","location":"116.397428,39.90923",...}

python .agents/skills/travel-planner/scripts/amap_api.py weather 110000
# → 实时天气 + 今日及未来 4 天预报

python .agents/skills/travel-planner/scripts/amap_api.py route "116.397428,39.90923" "116.322987,39.930636" walking
# → 距离、耗时（秒/分钟）、步骤指引；模式支持 walking / driving / transit
```

高德 Key 申请：高德开放平台 console.amap.com → 创建应用 → 申请 Web 服务 Key（免费）。

### 无 Key 时的行为

脚本返回 `{"error":"NO_AMAP_KEY", ...}` 并退出码 2；Agent 应降级为通用搜索获取
天气与路线信息，并在报告中标注数据为估算、来源为搜索。

## 输出报告结构

1. 目的地：城市、省份、最佳出行窗口
2. 未来 7 天逐日情报表：日期 | 天气 | 气温 | 降水/风力 | 空气质量 | 日出日落 | 穿衣/雨具建议
3. 本周人文清单：活动/展览/演出/节庆 | 时间 | 地点 | 预约要求 | 来源
4. 推荐行程（按天）：景点顺序 | 交通方式 | 单段耗时 | 当日总耗时 | 备注
5. 注意事项：天气风险、景区限流预约、证件、费用估算
6. 数据来源与口径：逐项标注来源；估算项明确标"估算"

## 注意事项

- 景区开放、预约、票价等信息易变，报告提示出行前再次核实。
- `AMAP_KEY` 属于敏感凭据：只从环境变量读取，禁止写入仓库、日志或报告。
- 技能内不包含任何 Key 或用户个人信息。
